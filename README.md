# Skad

Skad is a community archive for the languages of Kinnaur, preserving words, meanings, pronunciation, examples, and cultural context.

Browse and search across languages, share what you know without an account, and help improve records through moderator-reviewed contributions. The interface is available in Hindi and English.

Built with Elixir, Phoenix, SQLite, and S3-compatible media storage.

## Run locally

Install the Erlang and Elixir versions in [`.tool-versions`](.tool-versions), then run:

```sh
mix setup
mix phx.server
```

Open [localhost:4000](http://localhost:4000). See the [contributing guide](CONTRIBUTING.md#development-setup) for moderator access and local media storage.
